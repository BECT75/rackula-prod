# BECT75 Rackula Production

Dépôt autonome de déploiement production pour RACKULA chez BECT75.

La source applicative reste maintenue dans `BECT75/rackula`, conservé comme fork de `RackulaLives/Rackula` afin de préserver le suivi upstream.

La version publiée est explicitement figée dans `production-release.json`. Aucun push sur le dépôt source ne modifie automatiquement la production sans mise à jour de ce manifeste.

Production cible : `https://bect75.github.io/rackula-prod/`.
